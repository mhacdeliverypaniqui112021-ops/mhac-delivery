MHAC DELIVERY CUSTOMER APP V5 – TOP DELIVERY FORMULA + JOLLIBEE CATEGORY FLOW

Changes in this package:
1. DELIVERY RATE / FORMULA was removed from the lower Order Summary area.
2. DELIVERY RATE / FORMULA is now placed directly below the MHAC DELIVERY header so customers see it immediately.
3. Jollibee now opens into customer-facing categories:
   - Chickenjoy
   - Jolly Spaghetti
   - Burgers
   - Super Meals
   - Sides
   - Drinks
   - Desserts
4. Tapping Chickenjoy opens the product list with 1-pc, 2-pc, 4-pc, 6-pc and 8-pc items.
5. Product + opens the product details/add-on selection before Add to Cart.
6. Built-in Jollibee menu migration upgrades the old test menu (Burger List / Chicken List) automatically.
7. Existing custom menus are preserved unless they are the old built-in test Jollibee menu.
8. Maximum 2 stores, +P5 second store, 10% service fee, GPS/delivery calculation, admin, rider and Menu Manager remain included.
