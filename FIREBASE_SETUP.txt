MHAC DELIVERY — ONLINE ORDER V2 SETUP
=====================================

This version adds online order synchronization using Firebase Firestore.
It still keeps localStorage as a fallback for testing.

IMPORTANT: Firebase configuration is NOT included because it belongs to your Firebase project.

STEP 1 — Firebase project
1. Open https://console.firebase.google.com/
2. Create/select your MHAC DELIVERY Firebase project.
3. Add a Web App (</>) if you have not created one.
4. Copy the Firebase Web App config.

STEP 2 — Put your config in the ZIP
Open:
  firebase-config.js

Replace the blank values with your Firebase Web App config:
  apiKey
  authDomain
  projectId
  storageBucket
  messagingSenderId
  appId

STEP 3 — Enable Anonymous Login
Firebase Console → Authentication → Sign-in method → Anonymous → Enable.

STEP 4 — Create Firestore
Firebase Console → Firestore Database → Create database.

STEP 5 — Firestore rules for TESTING
Copy the contents of firestore.rules into Firestore Rules and Publish.
These rules are intentionally simple for testing. Before public launch we should add proper Admin/Rider authentication and role permissions.

STEP 6 — Upload to GitHub Pages
Upload ALL files from this ZIP to the ROOT of your repository.
Do not upload only index.html. Keep:
  index.html
  admin.html
  rider.html
  admin-menu.html
  firebase-config.js
  mhac-online.js
  logo.png

ONLINE FLOW
Customer places order
        ↓
Firebase Firestore: mhac_orders
        ↓
Admin sees new order automatically
        ↓
Admin assigns rider / changes status
        ↓
Rider sees order automatically
        ↓
Rider changes status
        ↓
Customer tracking updates automatically

MENU FLOW
Admin Menu Manager → PUBLISH MENU ONLINE
        ↓
Firestore: mhac_config/catalog
        ↓
Customer apps receive updated menu

NOTE
GitHub Pages is only the website host. Firebase provides the shared online database.
Do not put a Firebase service-account private key in this website.
