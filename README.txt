MHAC DELIVERY V8.4 - STORE MENU + CART TEST
================================================
Customer flow:
1. Tap Jollibee / McDonald's / Local Food.
2. The selected store's MENU appears.
3. Select Burger List or Chicken List.
4. Select a food, e.g. Burger Solo ₱99 or Chicken Solo ₱129.
5. Choose a drink from ADD DRINKS. Drinks are radio choices, each with its own added price.
6. Choose optional ADD-ONS.
7. Add to order and proceed to checkout.
8. GPS/routing/delivery fee remains in the same page.
9. A second store automatically adds ₱5. Maximum 2 stores.

IMPORTANT:
- This version uses localStorage key MHAC_MENU_V8_4 so old broken menu data will not hide the new test menu.
- MENU MANAGER remains editable.
- RESET TEST MENUS restores the built-in Jollibee/McDonald's/Local Food test menus.
