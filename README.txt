TEST FLOW:
1. Open index.html.
2. Choose Local Food (temporary testing store).
3. Add food and add-ons.
4. PLACE ORDER.
5. For distance testing while standing at the shop, enter a CUSTOMER test latitude/longitude and press USE TEST LOCATION & CALCULATE.
6. Check the actual road distance and delivery fee.
7. Open admin.html to accept/assign/status the order.
8. Open rider.html to update rider status.
9. Customer can use TRACK MY ORDER in the footer.

Fee:
1 km = ₱40; each succeeding billable km +₱10.
Second store = +₱5. Maximum 2 stores.

IMPORTANT:
This V8 demo shares orders/menu using browser localStorage. It is not yet a real multi-device backend. Firebase/online database is the next production step.
